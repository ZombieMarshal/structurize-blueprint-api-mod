# Structurize — Structure Blueprint API

[![Download Latest](https://img.shields.io/github/v/release/ZombieMarshal/structurize-blueprint-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/ZombieMarshal/structurize-blueprint-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

The blueprint and structure placement API used by MineColonies, enabling complex structure scanning.

## Features

- Scan and save any structure as a blueprint
- Place blueprints with rotation and mirroring
- Required by MineColonies and Domum Ornamentum
- Command-based placement for server admins
- Multiblock schematic format for sharing

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
